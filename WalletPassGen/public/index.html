Certificate Setup

Apple requires a signed certificate to install passes on iOS. You'll need an Apple Developer account ($99/yr).

  1. In Apple Developer Portal, create a Pass Type ID (e.g. pass.com.you.mypass).
  2. Generate and download the Pass Type ID Certificate (.cer file).
  3. Convert it to PEM format and export the private key: 
    openssl x509 -inform DER -in Certificates.cer -out certs/signerCert.pem
# Export private key from Keychain (right-click → Export → .p12), then:
openssl pkcs12 -in Certificates.p12 -nocerts -nodes -out certs/signerKey.pem
  4. Download the Apple WWDR G4 CA certificate: 
    curl -o certs/wwdr.pem https://www.apple.com/certificateauthority/AppleWWDRCAG4.cer
# If it downloads as DER format, convert it:
openssl x509 -inform DER -in certs/wwdr.pem -out certs/wwdr.pem
  5. Place all three files in the certs/ folder next to server.js.

Your certs/ folder is git-ignored — certificates never leave your machine.
